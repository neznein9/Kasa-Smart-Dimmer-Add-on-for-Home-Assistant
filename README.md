# Kasa Smart Dimmer Integration for Home Assistant
This is an integration for [Home Assistant](https://www.home-assistant.io/), to add extra actions for [Kasa Smart](https://www.kasasmart.com/) dimmer switches, such as the [KS220](https://www.kasasmart.com/us/products/smart-switches/kasa-smart-wifi-light-switch-dimmer-ks220).

This is not a full integration for Kasa devices. It is intended to work alongside the [TP-Link Smart Home](https://www.home-assistant.io/integrations/tplink/) integration, in order to add extra capabilities.

## Features
- [ ] Change the brightness of dimmer switches, without switching on the light
